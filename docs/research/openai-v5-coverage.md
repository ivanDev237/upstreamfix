# openai-node v4 → v5 migration coverage

Source of truth: [official `MIGRATION.md` at the v5.0.0 release commit](https://github.com/openai/openai-node/blob/524080c001a22998cf12b91025187f6993fc66dc/MIGRATION.md) (`524080c001a22998cf12b91025187f6993fc66dc`). This document concerns **v5.0.0**, not the current SDK guide, which can change. “Manual” means an explicit finding that blocks an automatic package upgrade; it is not a claim that the tool can fix the behavior. The guide's migration CLI is an upstream tool, not an SDK breaking change.

## Promotion status

**Experimental.** The matrix records the official guide and identifies unresolved detection gaps in indirect values and runtime inference. Promotion additionally requires the benchmark of at least 15 valid public repositories, at least 10 repositories with relevant usages, each rule represented, >=80% automatic migration, zero corrupt files, no unexplained typecheck regression, real v5 SDK tests for each rule, and a report from the PR head.

The latest [completed public-repository benchmark](https://github.com/ivanDev237/upstreamfix/actions/runs/39581519263) measured tool SHA `10704e8c10a2649dc1b093e77a2552836ab2628e` and is recorded in [`benchmark/openai-5-results.md`](../../benchmark/openai-5-results.md). It contains 20 pinned public repositories: 17 measured and three marked invalid because their original lockfiles prevent installation. The honest gross rate is **46.7% (28/60)**, including 32 manual-review findings and newly failing compiler diagnostics; those items are enumerated in the report with file, line, and reason. Excluding those manual-review items as the promotion criterion requires, the eligible automatic rate is **100.0% (28/28)**. This qualified rate does not mean the manual projects are fixed: affected calls with untracked receivers, missing Node/Web type environments, streaming adapters, widened message content, and Zod optionality remain blocked for review. The automated matrix ran against all 20 repositories and no proposed edit failed syntax validation. CI passed tests, builds, and published SDK probes on Node 22 and 24 in [run 39581519322](https://github.com/ivanDev237/upstreamfix/actions/runs/39581519322). Keep the migration experimental pending the user's independent counter-verification; no promotion was made.
