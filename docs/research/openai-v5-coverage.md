# openai-node v4 → v5 migration coverage

Source of truth: [official `MIGRATION.md` at the v5.0.0 release commit](https://github.com/openai/openai-node/blob/524080c001a22998cf12b91025187f6993fc66dc/MIGRATION.md) (`524080c001a22998cf12b91025187f6993fc66dc`). This document concerns **v5.0.0**, not the current SDK guide, which can change. “Manual” means an explicit finding that blocks an automatic package upgrade; it is not a claim that the tool can fix the behavior. The guide's migration CLI is an upstream tool, not an SDK breaking change.

## Promotion status

**Experimental.** The matrix records the official guide and identifies unresolved detection gaps in indirect values and runtime inference. Promotion additionally requires the benchmark of at least 15 valid public repositories, at least 10 repositories with relevant usages, each rule represented, >=80% automatic migration, zero corrupt files, no unexplained typecheck regression, real v5 SDK tests for each rule, and a report from the PR head.

The [completed pull-request benchmark](https://github.com/ivanDev237/upstreamfix/actions/runs/39513280362) measured source SHA `0bd97667a6a3b870b41fc7e58d174ee35d58c842` and is recorded in [`benchmark/openai-5-results.md`](../../benchmark/openai-5-results.md). It contains 20 pinned public repositories: 17 measured and three marked invalid because their original lockfiles prevent installation. Fourteen measured repositories have detected migration items. The automatic rate is **29.2% (14/48)**, below the required 80%. The denominator includes conservative manual findings and newly failing compiler diagnostics, not individual call sites. No rewritten file failed syntax validation. Previously passing typechecks that failed with v5 have file and line findings for review; this is not evidence that those projects work after migration. Published v4 and v5 SDK compilation tests pass in [CI](https://github.com/ivanDev237/upstreamfix/actions/runs/39513280313). The measured gaps include beta-chat clients not tracked through every property shape, removed deep imports, path parameter changes, and environment types. Keep the migration experimental and disabled from automatic discovery.
